# Boi Training — Touro Fit

Aplicativo de treino voltado para **profissionais** (professores e personal trainers) e **alunos**.

O objetivo é facilitar a rotina de treinos: o aluno acompanha e executa os treinos no app, e o profissional organiza e acompanha o progresso dos alunos.

Este repositório contém o protótipo visual (vitrine de telas) do app.
